# Proyectos_Python

Repositorio con pequeños ejercicios de práctica en python.

## Estructura para Jupyter

Los mini proyectos se organizan dentro de la carpeta `/jupyter`, donde cada
proyecto tiene su propia carpeta:

```text
jupyter/
├── mini_proyecto_01/
├── mini_proyecto_02/
└── mini_proyecto_03/
```

Cada carpeta está pensada para guardar los notebooks `.ipynb` y los archivos
relacionados de ese mini proyecto.
